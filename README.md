# 🌐 Laboratório de Redes CCNA (200-301)

Repositório dedicado à implementação, documentação e validação de laboratórios práticos de redes de computadores, desenvolvidos com o **Cisco Packet Tracer**.

O objetivo é aplicar conhecimentos de redes, infraestrutura, roteamento, switching e segurança de dispositivos, documentando as topologias, configurações, testes realizados e aprendizados de cada projeto.

---

## 🛠️ Tecnologias e Conceitos do Portfólio

- **Roteamento:** OSPF (single-area e multi-area), rotas estáticas e rotas padrão.
- **Switching:** VLANs, trunking 802.1Q, Router-on-a-Stick, STP, EtherChannel e Port Security.
- **Serviços de rede:** DHCP, DHCP Relay, DNS e SSH.
- **Conectividade e borda:** NAT/PAT, tradução estática de endereços e roteamento para redes externas simuladas.
- **Segurança de rede:** ACLs padrão e estendidas, controle de acesso e hardening de switches e roteadores.
- **Ferramenta de laboratório:** Cisco Packet Tracer.

Os conceitos são documentados individualmente nos projetos, de acordo com as tecnologias efetivamente implementadas e testadas em cada laboratório.

## 🚀 Como Executar os Laboratórios

1. Acesse a pasta do laboratório desejado.
2. Consulte o README específico para conhecer os requisitos e a topologia.
3. Baixe ou clone o repositório.
4. Abra o arquivo `.pkt` correspondente no Cisco Packet Tracer, quando disponibilizado.
5. Siga as instruções de configuração e validação documentadas no projeto.

**Requisito:** Cisco Packet Tracer compatível com os arquivos disponibilizados.
